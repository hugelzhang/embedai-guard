# EmbedAI Guard — 3 分钟演示视频脚本

> 录制工具: OBS Studio / ScreenToGif
> 终端: Windows Terminal (深色主题)
> 项目: STM32L475 潘多拉 IoT 开发板

---

## 时间线

### 0:00-0:15 开场

```
画面: 终端全屏，深色背景
操作: 无
旁白: "嵌入式固件开发中，60% 的时间花在 debug 上。
      大量问题是已知规则的违规——编码规范、引脚冲突、中断优先级。
      EmbedAI Guard 把它们变成自动化门禁。"
```

### 0:15-0:45 guard plan — 一键分析

```
画面: 终端输入命令
操作: guard plan .
旁白: "一条命令分析整个项目。自动检测芯片型号 STM32L475、
      识别 HAL 库、推荐 10 条规则、匹配芯片契约。
      告诉你接下来该跑什么。"
```

### 0:45-1:30 guard scan — 13 条规则

```
画面: guard scan . 输出在终端滚动
操作: guard scan HARDWARE/
重点: 彩色终端输出，ERROR 红色高亮
旁白: "13 条编码规范一键扫描。阻塞延时、动态内存、ISR 过长、
      乘除运算——全部自动检测，精确定位到行号和列号。
      55 个文件，1 秒完成。"
```

### 1:30-2:00 guard fix — 自动修复

```
画面: diff 对比效果
操作: 
  guard fix . --dry-run   （预览修复）
  guard fix . --apply     （执行修复）
旁白: "它不是只告诉你哪里错了——能改的自动帮你改。
      乘除改移位、未初始化变量加初始化，改完语义不变。
      22 处修复，秒级完成。"
```

### 2:00-2:45 guard check — 芯片契约

```
画面: guard check 引脚分配表
操作: guard check . --contract stm32l475vet6.json
旁白: "这是目前市面上唯一能做的事——从代码中自动提取引脚配置，
      对比芯片手册验证冲突。STM32L475 82 个引脚，
      25 个已分配，0 errors。
      还支持华大 CIU32F003 和汇春 YS32F003。"
```

### 2:45-3:00 结尾

```
画面: 三个芯片 logo + 三条命令
旁白: "EmbedAI Guard — 从三条命令开始，
      让 SDK 质量从'靠人审查'变成'自动门禁'。
      github.com/xxx/embedai-guard"
```
