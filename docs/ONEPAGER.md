# EmbedAI Guard — 嵌入式固件 AI 质量门禁

> 给 MCU 原厂 SDK 负责人的一页纸

---

## 我们做什么

**三道门禁，把 SDK 质量问题拦在发布之前：**

| 门禁 | 一句话 | 示例 |
|------|--------|------|
| **约束扫描** | 自动检测 + 自动修复编码规范违规 | `delay_ms(500)` → 提示改为定时器 |
| **芯片契约** | 引脚/时钟/DMA/中断 四维硬件冲突检测 | PA1 被配成 USART1，但手册上 PA1 的 AF7 是 USART2_RTS |
| **Golden Trace** | 逻辑分析仪波形自动对比回归 | 改了 SPI 驱动 → 自动对比波形 → 时序偏移 18ns → 告警 |

## 为什么原厂需要

```
原厂 SDK 团队现状：
├── 10 人写 SDK
├── 20 人 FAE 帮客户 debug  
├── 客户投诉 40% 是 SDK bug，30% 是文档不清，20% 是引脚配错
└── 每次 SDK 发版人工审查依赖资深工程师经验

引入 Guard 后：
├── 约束扫描 → SDK bug 减少 50%（delay/malloc/乘除/ISR 自动拦截）
├── 芯片契约 → 引脚配错在编译阶段发现（不等烧录后 debug）
├── FAE 工时减少 30-40%
└── 客户 SDK 集成速度提升
```

## 技术事实

| 指标 | 数据 |
|------|------|
| 规则数 | 13 条（覆盖 MISRA-C 核心 + 嵌入式专项） |
| 支持芯片 | STM32L475 + 华大 CIU32F003 + 汇春 YS32F003 |
| 检出能力 | STM32L475 项目 55 文件，14 ERROR + 200 WARNING |
| 自动修复 | 乘除→移位、静态内存替换，秒级完成 |
| 新增芯片 | 一份 JSON 契约文件（18-82 行），半天工作量 |
| 集成方式 | CLI + VS Code 扩展 + CI/CD (JSON/JUnit) |
| 安装 | `pip install embedai-guard`，Python 3.10+ |
